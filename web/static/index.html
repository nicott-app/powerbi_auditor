Cómo obtener tu API Key de Groq
¿Para qué sirve esta clave?

El análisis estático base (gráfico de salud, elementos huérfanos, buenas prácticas) funciona sin necesidad de clave. Añadirla desbloquea la Inteligencia Artificial avanzada:

  • Optimizador DAX: La IA reescribe automáticamente tus métricas ineficientes o mal estructuradas.
  • Documentación Inteligente: Redacta en lenguaje natural el Resumen Ejecutivo del archivo Word (.docx).

Groq ofrece uno de los motores de IA más rápidos del mundo (100% gratuito). Sigue estos pasos para obtener tu clave:

  1. Crear una cuenta
    Entra en console.groq.com y regístrate.
  2. Ir a API Keys
    En el menú lateral izquierdo, haz clic en API Keys.
  3. Generar clave secreta
    Pulsa Create API Key. Copia la cadena (empieza por gsk_...).
  4. Pegarla en la herramienta
    Pega la clave en el recuadro "API KEY DE GROQ" de esta página para desbloquear el Refactorizador Avanzado.
